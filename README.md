# 🏥 E-Hospital Management System (Java)

A **console-based E-Health Care Management System** developed using **Core Java** concepts.  

This project simulates basic hospital operations such as **user authentication, patient record management, diagnosis tracking, and billing**, using **file handling for persistent storage**.

---

## ✨ Features

🔐 **User Authentication**  
- Sign Up & Login system  
- Secure credential storage using file handling  

👨‍⚕️ **Patient Management**  
- Add new patient records  
- Store personal and medical details  
- Each patient has a unique file for history tracking  

🩺 **Diagnosis Management**  
- Add doctor details, symptoms, diagnosis, and medicines  
- Automatically records date & time of diagnosis  

📄 **Patient History**  
- View complete medical history from stored files  

💰 **Billing System**  
- Calculates total bill based on:  
  - Number of days stayed  
  - Ward charges  
  - Doctor fees  
  - Service charges  

🆘 **Help Section**  
- Explains system usage for new users  

---

## 🛠️ Technologies Used

- **Java (Core Java)**  
- **Object-Oriented Programming (OOP)**  
  - Abstraction (Interface)  
  - Encapsulation (Classes & Private Fields)  
- **File Handling**  
  - BufferedReader  
  - BufferedWriter  
  - FileReader  
  - FileWriter  
- **Date & Time API**  
  - LocalDateTime  
  - DateTimeFormatter  

---

## ✅ Conclusion

The **E-Hospital Management System** successfully demonstrates the use of **Core Java and Object-Oriented Programming principles** to build a real-world, menu-driven application.  

By integrating **authentication, patient record management, diagnosis tracking, billing, and file-based persistence**, the system ensures organized data handling and practical usability.  

This project strengthens understanding of **Java fundamentals, file handling, modular design, and problem-solving**, making it a strong foundation for advanced enhancements such as **database integration, role-based access, and GUI development**.
